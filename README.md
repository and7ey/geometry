# GeoMaster — учебник-тренажёр по геометрии 7–8

Интерактивная веб-платформа для изучения, запоминания и повторения теории геометрии 7–8 класса. Без регистрации, сервера и внешней базы данных: весь прогресс хранится в `LocalStorage` браузера.

**Демо:** https://and7ey.github.io/geometry/

## Что внутри

- **155 учебных элементов** в **21 теме**, 7 типов материала: определения, свойства, признаки, теоремы, следствия, аксиомы, формулы.
- **75 авторских заданий**: один и несколько ответов, верно/неверно, сопоставление, пропуски в формулировках, различение свойства и признака, прямые и обратные теоремы.
- **20 шаблонов числовых задач** с пошаговыми решениями: углы, площади, теорема Пифагора, подобие, тригонометрия.
- Параметрические **SVG-схемы** с подписями, которые корректно работают в светлой и тёмной теме.
- **Интервальное повторение**: уровни 0–6 и интервалы 1 → 3 → 7 → 14 → 30 → 60 дней; ошибка сокращает интервал, подсказка блокирует повышение уровня.
- **Сбалансированная выборка**: короткое занятие берёт материалы по одному из разных тем, а не первые подряд из одной.
- Раздельные показатели **воспроизведения** и **понимания**.
- **Статистика**: просмотрено / изучено / освоено, точность, серия дней, активность за 14 дней, результаты по классам, темам и категориям, история занятий, слабые места.
- Светлая и тёмная темы, системная тема по умолчанию, адаптивная вёрстка, управление с клавиатуры.
- Экспорт/импорт JSON и полный сброс данных с подтверждением.

## Режимы

| Режим | Что делает |
|---|---|
| Изучение | Полная карточка: формулировка, объяснение, пример, типичные ошибки, схема, связи. Отметки «изучено» и «в избранное». |
| Карточки | 6 типов лицевой стороны, четыре честные самооценки. «Не знал» возвращает карточку в конец занятия. |
| Воспроизведение | Свободный ответ, подсказка, эталон, автопроверка по ключевым элементам и самооценка. |
| Тест | Все типы заданий, мгновенная проверка, объяснение и разбор ошибок. |
| Экзамен | Случайная выборка, без подсказок и немедленной обратной связи, итоговая устойчивость знаний. |
| Ошибки | Персональная подборка слабых, просроченных и подсказанных материалов. |
| Маршрут темы | 7 этапов: определения → свойства → признаки → различение → воспроизведение → тест → ошибки. |

Конфигуратор: класс 7 / 8 / оба, сложность, 7 категорий + «всё», мультивыбор тем, количество 5/10/20/30/все, отбор «новые / изученные / ошибки / пора повторить» и исключение освоенного.

## Контент

Формулировки ориентированы на базовую школьную программу (Атанасян 7–9). Элементы вне базового минимума помечены как **расширение**. Контент отделён от интерфейса и лежит в `src/content/`:

```
src/content/
  g7/basics.ts      # начала геометрии, смежные и вертикальные углы
  g7/triangles.ts   # треугольники, равенство, медианы, равнобедренный
  g7/parallel.ts    # параллельность, сумма углов, прямоугольные, окружность
  g8/quads.ts       # четырёхугольники, параллелограмм, трапеция, средние линии
  g8/areas.ts       # площади, Пифагор
  g8/similarity.ts  # подобие, тригонометрия
  g8/circle.ts      # касательные, углы, вписанная и описанная окружности
  topics.ts         # темы и разделы
  drills/           # авторские задания
```

Каждый элемент содержит id, название, класс, тему, категорию, сложность, полную формулировку, простое объяснение, пример, типичные ошибки, связи, источник, признак `base/extended`, при необходимости — схему, условие/заключение теоремы, формулу и ключевые элементы для свободного ответа.

### Добавить материал

1. Создайте объект через `defineItem({...})` в подходящем файле (или новом файле в `content/g7` / `content/g8`).
2. Импортируйте массив в `src/content/index.ts` и добавьте его в `ITEMS`.
3. Запустите `npm test`: валидатор проверит уникальность id, существование темы и связей, обязательные поля, схемы и задания.

Новые темы добавляются в `src/content/topics.ts`; UI подхватит их автоматически.

## Запуск

Требования: Node.js 20+ (проверено на Node 26).

```bash
npm install
npm run dev
```

Откройте `http://localhost:5173/geometry/`.

```bash
npm run build     # проверка типов + production-сборка в dist/
npm run preview   # локальный просмотр сборки
npm test          # 33 теста логики и контента
```

## Деплой

Проект собирается статикой. Для GitHub Pages используется ветка `gh-pages`:

```bash
npm run deploy
```

`vite.config.ts` задаёт `base: '/geometry/'`, поэтому сайт доступен по адресу `https://and7ey.github.io/geometry/`. Роутинг — `HashRouter`, дополнительная настройка 404 не нужна. После первого деплоя в настройках репозитория нужно выбрать источник Pages: ветка `gh-pages`, папка `/`.

## Данные

Ключ `geomaster.v1` содержит версионированное состояние: настройки, прогресс по элементам, агрегаты по дням, последние 50 занятий, маршруты и последнюю подборку. История каждого элемента ограничена 12 событиями; учебный контент в хранилище не дублируется.

- Безопасное чтение: повреждённый JSON сохраняется в `geomaster.v1.corrupt`, приложение стартует с чистого состояния.
- Миграция: данные без поля `version` автоматически переводятся в версию 1.
- Переполнение квоты: повторная запись без истории и с сокращённой историей занятий.
- Синхронизация между вкладками через событие `storage`.
- Экспорт/импорт — JSON-файл с проверкой структуры; импорт заменяет состояние после подтверждения.
- Сброс прогресса и полный сброс — только через модальное подтверждение (полный — с вводом слова `УДАЛИТЬ`).

## Критерии

- **Просмотрено** — карточка открыта. Это не знание.
- **Изучено** — успешное воспроизведение без подсказки или явная отметка.
- **Освоено** — уровень 5+, два успешных воспроизведения подряд, два верных применения, интервал от 14 дней, нет нерешённых ошибок.
- Точность считается по карточкам, тестам и свободным ответам; тест не заменяет воспроизведение.
- Серия дней не сбрасывается в наказание: пропуск просто оставляет очередь повторений на месте.

## Стек

React 19, TypeScript, Vite 8, Tailwind CSS 4, React Router (HashRouter), Vitest. Без UI-библиотек, без бэкенда, без аналитики. Шрифты Literata и Golos Text лежат локально в `src/assets/fonts`.

```
src/
  app/            провайдер состояния
  components/     UI-примитивы, схемы, карточки
  content/        учебная база и задания
  features/       компоненты заданий и маршрутов
  pages/          экраны
  services/       storage, scheduling, filters, quiz, statistics, session
  types/          общие типы
  utils/          форматирование
tests/            проверки контента и логики
```

## Ограничения

- Автопроверка свободного ответа работает по ключевым элементам и пересечению слов, а не «понимает» математический смысл. В интерфейсе это указано; окончательная оценка — за пользователем.
- Схемы интерактивны на уровне подписей и подсветки, но не перетаскиваемых вершин; чертежи не являются доказательством.
- Прогресс не синхронизируется между устройствами — только экспорт/импорт JSON.
- Числовые задачи и большинство заданий опираются на базовую программу; спорные для разных учебников элементы помечены.
